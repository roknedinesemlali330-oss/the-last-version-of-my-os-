# MyOS: نظام لنكس بواجهة مخصصة

نظام مبني على Debian 13، وواجهته (الرف والمشغّل) مكتوبة بـ Quickshell.

## وش يسوي كل ملف؟

| الملف | دوره | يشبه في Node.js |
|---|---|---|
| `auto/config` | إعدادات البناء (النسخة، الاسم، اللغة) | `package.json` (الإعدادات العامة) |
| `config/package-lists/myos.list.chroot` | الحزم التي تُثبَّت في النظام | `dependencies` |
| `config/archives/` | مصدر إضافي للحزم (backports) لأن Quickshell فيه | `.npmrc` / registry |
| `config/includes.chroot_after_packages/` | ملفات تُنسخ كما هي داخل النظام | مجلد `src/` |
| ↳ `etc/sway/config` | إعدادات مدير النوافذ | |
| ↳ `etc/myos/shell.qml` | **كود الواجهة** (هنا تشتغل أغلب الوقت) | `index.js` |
| ↳ `etc/profile.d/myos-sway.sh` | يشغّل sway تلقائياً عند الإقلاع | |
| `.github/workflows/build.yml` | يخلي GitHub يبني الـ ISO | `scripts.build` / CI |

كل ما في هذا المجلد يُنسخ كما هو إلى النظام (بدون أسماء تبدأ بنقطة حتى يسهل رفعها على GitHub).

## طريقة التشغيل

1. أنشئ مستودع جديد على GitHub (اسمه مثلاً `my-os`).
2. ارفع كل محتويات هذا المجلد إليه (مع المجلد المخفي `.github`).
3. افتح تبويب **Actions** في المستودع، واختر `build-iso`، ثم **Run workflow**.
4. انتظر البناء (غالباً من 20 إلى 40 دقيقة).
5. حمّل ملف `myos-iso` من نهاية صفحة التشغيل، وفك ضغطه لتحصل على ملف ISO.
6. شغّله من فلاشة أو VirtualBox.

## اختصارات النظام

| الاختصار | الوظيفة |
|---|---|
| `Super + Enter` | فتح الطرفية |
| `Super + B` | فتح المتصفح |
| `Super + Shift + Q` | إغلاق النافذة |
| `Alt + Shift` | تبديل لغة الكتابة |

(`Super` هو زر ويندوز.)

## ملاحظات مهمة

- هذه **المرحلة الأولى**: الرف والمشغّل الأساسي. لم يُختبر البناء بعد، ومن المتوقع تظهر أخطاء في أول تشغيل، وهذا طبيعي. انسخ سطر الخطأ وأصلحه مع Claude.
- النوافذ حالياً بزوايا حادة، لأن sway لا يدعم الزوايا الدائرية. نحتاج مدير نوافذ فرعي اسمه SwayFX في مرحلة لاحقة.
- المشغّل بدون بحث بعد، ولوحة الإعدادات السريعة غير مضافة، وكلاهما في المراحل القادمة.

## المرحلة 2 (الدفعة 1)

- أيقونات حقيقية (Papirus) وخلفية مخصصة وثيم GTK.
- المشغّل يعرض كل التطبيقات المثبتة مع بحث.
- لوحة إعدادات سريعة: الشبكة، لغة الكيبورد، مدير المهام، الخروج، إعادة التشغيل، الإطفاء.
- تطبيقات: Thunar، Mousepad، Galculator، Ristretto، Evince، mpv، File Roller، LXTask، Firefox.
- اختصارات جديدة: `Super+E` الملفات، `Print` لقطة شاشة، `Super+Shift+S` لقطة منطقة.

## المرحلة 3: Hyprland

- النظام يشغّل Hyprland أولاً (زوايا دائرية، ظلال، أنيميشن). لو فشل يرجع تلقائياً إلى sway.
- الإعدادات في `etc/myos/hyprland.conf`.
- `Super+F` تكبير النافذة، `Super+Shift+F` ملء الشاشة، `Super+V` تحويل النافذة عائمة، `Alt+F4` إغلاق.
- `Super + سحب بالماوس` لتحريك النافذة، و`Super + زر الماوس الأيمن` لتغيير حجمها.

## المرحلة 4 (الدفعة 5)

- تصحيح لغة الكيبورد: العربية في XKB اسمها `ara` وليس `ar`.
- أزرار نافذة (عائم، تكبير، إغلاق) على الرف تعمل على النافذة النشطة.
- تطبيق إعدادات مستقل (`etc/myos/settings/shell.qml`): الواي فاي، الصوت والسطوع، الكيبورد، الخلفيات، عن النظام.
- لوحة سريعة فيها تحكم بالصوت والسطوع.
- لتشغيل الإعدادات يدوياً لرؤية الأخطاء: `qs -p /etc/myos/settings`

## المرحلة 5 (كل الدفعات)

- إعدادات موسعة: الواي فاي، البلوتوث، الصوت، المظهر (فاتح/داكن + ألوان)، الرف، النوافذ، الشاشة، الكيبورد، الخلفيات، النظام، عن النظام.
- ملف الإعدادات: `~/.config/myos/settings.json` (يقرأه الرف كل ثانيتين).
- مؤشر لغة الكيبورد والبطارية على الرف.
- المثبّت Calamares (تجريبي، جرّبه داخل جهاز افتراضي فقط) ومتجر برامج مع Flatpak.
- حزم أجهزة: بلوتوث، طباعة، تعريفات واي فاي وكروت، ومعالجات microcode.
- نسخة احتياط للواجهة: `etc/myos/stable/shell.qml`، واختصار `Super+Shift+R` للرجوع لها.
